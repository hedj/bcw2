3. Core¶

3.1. Overview¶

The core runs every thread through one pipeline.

3.2. Rotation¶

REQUIREMENT core.rotation

The core shall give the turn after thread t to thread t + 1.

Formal twin
def core_rotate(turn):
    return {'next': turn + 1}

Serves: design.timing

Verilog: build/rtl/core/core_rotate.v
module core_rotate (input wire [2:0] turn, output wire [2:0] next);
    assign next = turn + 3'd1;
endmodule

Why: see the explanation

OPEN The thread count is not settled.

DEFINITION core.turn

A turn is a thread’s cycle in the rotation.

Serves: core.core

DEFINITION core.core

The core runs the threads in turn.

3.4. Explanation¶

Rotation

RATIONALE
